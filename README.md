# 红楼梦图谱 · Dream of the Red Chamber Atlas

《红楼梦》人物谱系、关系图谱、判词、诗词、事件与地点的结构化资料库。
技术栈与「大宋全局志」一致：**SQLite 数据源 + 标准库 API + 零依赖前端**。

## 快速开始

```bash
cd honglou-atlas
python3 db/init_db.py      # 首次建库
./start.sh                 # 默认 http://127.0.0.1:8600
```

不要直接双击 `index.html`——浏览器在 `file://` 下无法读取 API。

## 三个核心视图

- **谱系**（`#lineage`）：按家族切换，世代自上而下，配偶以虚线相连；点击人物看详情。
- **关系图**（`#graph`）：力导向布局，按家族分簇；可按亲缘/主仆/情缘/同人筛选；悬停显示关系名。
- **人物 → 事件**：任意人物详情先列「出场事件」（带回数），再列人物关系，可继续跳转。

## 移动端

- 顶栏折叠为 ☰ + 图标检索，正文与弹窗字号、间距按小屏重排
- 谱系图与关系图保留可读字号，改为**容器内横向滑动**（附滑动提示），并自动把根节点/图心滚到视野中央
- 人物页筛选改为两行：搜索占满一行，家族/身份并排
- 详情弹窗在小屏为全屏抽屉，出场事件排在关系之前
- 数据表格横向滚动，避免挤压

## API

| 路径 | 说明 |
|---|---|
| `/api/bootstrap` | 全量数据（条目、关系、谱系、面板） |
| `/api/items/<id>` | 条目详情，含关系与事件 |
| `/api/search?q=` | 检索 |

## 数据维护

数据写在 `tools/build_seed.py`（可读的 Python 结构），改完：

```bash
python3 tools/build_seed.py     # 生成 db/seed.json
python3 db/init_db.py --force   # 重建数据库
```

## 说明

判词、诗词取通行本文字；人物结局以通行本（程乙本）为主，脂本异文另注。
谱系为便于阅读做了简化：只收主要人物与直系血亲，旁支、续书人物从略。
